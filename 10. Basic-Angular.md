# Basic Angular Interview Questions & Answers

> A beginner-friendly guide covering 30 foundational Angular concepts for entry-level and junior developer interviews.

---

## 1. What is Angular and how does it differ from AngularJS?

Angular is a TypeScript-based, open-source front-end framework by Google for building single-page applications (SPAs).

| Aspect         | AngularJS (1.x)      | Angular (2+)            |
| -------------- | -------------------- | ----------------------- |
| Language       | JavaScript           | TypeScript              |
| Architecture   | MVC / `$scope`     | Component-based         |
| Mobile support | No                   | Yes                     |
| Compilation    | Runtime only         | AOT and JIT             |
| Performance    | Digest cycle, slower | Faster change detection |

---

## 2. What are the main building blocks of an Angular application?

- **Components** — UI + logic
- **Templates** — HTML views
- **Directives** — change DOM behavior
- **Services** — shared business logic/data
- **Pipes** — transform displayed values
- **Modules / Standalone APIs** — organize and bootstrap code
- **Routing** — navigation between views

---

## 3. What is a Component?

A component controls a part of the screen. It is a TypeScript class decorated with `@Component`, linked to a template and styles.

```typescript
@Component({
  selector: 'app-hello',
  standalone: true,
  template: `<h1>Hello {{ name }}</h1>`,
  styles: [`h1 { color: teal; }`]
})
export class HelloComponent {
  name = 'Angular';
}
```

---

## 4. What is a Module (NgModule) and what are Standalone Components?

An `NgModule` groups components, directives, pipes, and services (`declarations`, `imports`, `providers`, `bootstrap`).

Since Angular 14+ (default since v17), **standalone components** declare their own dependencies via `imports`, making NgModules optional.

```typescript
@Component({
  standalone: true,
  selector: 'app-list',
  imports: [CommonModule, RouterLink],
  templateUrl: './list.component.html'
})
export class ListComponent {}
```

## 5. What is the Angular CLI?

A command-line tool to create, build, test, and serve Angular apps.

```bash
npm install -g @angular/cli
ng new my-app          # create project
ng serve               # dev server (localhost:4200)
ng generate component user   # or: ng g c user
ng build               # production build
ng test                # unit tests
```

## 6. What is a Template and what is Data Binding?

A template is the HTML of a component. **Data binding** synchronizes data between the component class and the view.

| Type             | Syntax                  | Direction     |
| ---------------- | ----------------------- | ------------- |
| Interpolation    | `{{ value }}`         | Class → View |
| Property binding | `[property]="value"`  | Class → View |
| Event binding    | `(event)="handler()"` | View → Class |
| Two-way binding  | `[(ngModel)]="value"` | Both          |

---

## 7. What is the difference between Interpolation and Property Binding?

- Interpolation converts an expression to a string: `<img src="{{ url }}">`.
- Property binding sets a DOM property with the actual value (any type): `<img [src]="url">`, `<button [disabled]="isBusy">`.

Use property binding for non-string values such as booleans and objects.

---

## 8. What is Event Binding?

Listens to DOM or component events and calls a method.

```html
<button (click)="save()">Save</button>
<input (keyup.enter)="search($event)">
```

---

## 9. What is Two-Way Binding?

Combines property and event binding ("banana in a box" `[()]`). Requires `FormsModule` for `ngModel`.

```html
<input [(ngModel)]="username">
<p>{{ username }}</p>
```

Equivalent to `[ngModel]="username" (ngModelChange)="username = $event"`.

## 10. What are Directives and their types?

Directives add behavior to DOM elements.

1. **Component** — directive with a template
2. **Structural** — change DOM structure (`*ngIf`, `*ngFor`, `ngSwitch`)
3. **Attribute** — change appearance/behavior (`ngClass`, `ngStyle`, custom directives)

```typescript
@Directive({ selector: '[appHighlight]', standalone: true })
export class HighlightDirective {
  constructor(el: ElementRef) { el.nativeElement.style.background = 'yellow'; }
}
```

---

## 11. What is the difference between `*ngIf` and `[hidden]`?

- `*ngIf` **adds/removes** the element from the DOM (component is created/destroyed).
- `[hidden]` keeps the element in the DOM and just toggles CSS `display: none`.

Use `*ngIf` to save resources when the content is rarely shown; use `[hidden]` for frequent toggles.

## 12. How do you loop over a list (`*ngFor` / `@for`)?

```html
<li *ngFor="let user of users; let i = index; trackBy: trackById">
  {{ i }} - {{ user.name }}
</li>
```

```typescript
trackById(index: number, user: User) { return user.id; }
```

`trackBy` helps Angular re-render only changed items.

---

## 13. What is the new Control Flow syntax?

Introduced in Angular 17, built-in blocks replace `*ngIf`, `*ngFor`, `ngSwitch`:

```html
@if (user) {
  <p>{{ user.name }}</p>
} @else {
  <p>No user</p>
}

@for (item of items; track item.id) {
  <li>{{ item.name }}</li>
} @empty {
  <li>No items</li>
}

@switch (status) {
  @case ('ok') { <span>OK</span> }
  @default { <span>Unknown</span> }
}
```

`track` is required in `@for`.

## 14. What are Pipes?

Pipes transform values in templates.

```html
{{ today | date:'shortDate' }}
{{ price | currency:'USD' }}
{{ name | uppercase }}
{{ data$ | async }}
```

Custom pipe:

```typescript
@Pipe({ name: 'truncate', standalone: true })
export class TruncatePipe implements PipeTransform {
  transform(value: string, limit = 20): string {
    return value.length > limit ? value.slice(0, limit) + '…' : value;
  }
}
```

---

## 15. What is the difference between Pure and Impure Pipes?

- **Pure** (default): runs only when the input reference/primitive changes. Fast.
- **Impure** (`pure: false`): runs on every change detection cycle. Needed for mutable inputs but costly. `async` is impure.

## 16. What is a Service?

A class holding reusable logic or shared state (API calls, logging, caching), registered with DI.

```typescript
@Injectable({ providedIn: 'root' })
export class UserService {
  private http = inject(HttpClient);
  getUsers() { return this.http.get<User[]>('/api/users'); }
}
```

---

## 17. What is Dependency Injection?

A design pattern where a class receives its dependencies from Angular's injector instead of creating them.

```typescript
export class UserComponent {
  private userService = inject(UserService);   // modern
  // constructor(private userService: UserService) {}  // classic
}
```

Scopes: `providedIn: 'root'` (singleton app-wide), component `providers` (per component instance).

---

## 18. What are `@Input()` and `@Output()`?

They enable parent–child communication.

```typescript
// child
@Input() title = '';
@Output() selected = new EventEmitter<string>();
pick() { this.selected.emit(this.title); }
```

```html
<!-- parent -->
<app-card [title]="'Hello'" (selected)="onSelected($event)"></app-card>
```

Newer equivalents: `input()`, `output()` signal-based functions.

## 19. What are Component Lifecycle Hooks?

| Hook                   | When                                |
| ---------------------- | ----------------------------------- |
| `ngOnChanges`        | Input property changes              |
| `ngOnInit`           | Once after first inputs are set     |
| `ngDoCheck`          | Every change detection run          |
| `ngAfterContentInit` | After projected content initialized |
| `ngAfterViewInit`    | After view/children initialized     |
| `ngOnDestroy`        | Before destruction (cleanup)        |

---

## 20. What is the difference between `constructor` and `ngOnInit`?

- `constructor` is a TypeScript feature, used for dependency injection and simple field initialization; inputs are not yet available.
- `ngOnInit` is an Angular hook called after inputs are set; put initialization logic and data fetching here.

## 21. What is Routing in Angular?

The Router maps URLs to components for SPA navigation.

```typescript
export const routes: Routes = [
  { path: '', component: HomeComponent },
  { path: 'users/:id', component: UserDetailComponent },
  { path: '**', component: NotFoundComponent }
];
```

```html
<a routerLink="/users/1">User 1</a>
<router-outlet></router-outlet>
```

Read params with `ActivatedRoute` or `input()` binding; navigate in code with `Router.navigate()`.

---

## 22. What are Route Guards?

Functions/classes that control navigation: `canActivate`, `canActivateChild`, `canDeactivate`, `canMatch`, `resolve`.

```typescript
export const authGuard: CanActivateFn = () => {
  return inject(AuthService).isLoggedIn() || inject(Router).createUrlTree(['/login']);
};

{ path: 'admin', component: AdminComponent, canActivate: [authGuard] }
```

---

## 23. What is Lazy Loading?

Loading routes/components only when needed to reduce the initial bundle size.

```typescript
{ path: 'admin', loadComponent: () => import('./admin/admin.component').then(m => m.AdminComponent) }
{ path: 'shop', loadChildren: () => import('./shop/shop.routes').then(m => m.SHOP_ROUTES) }
```

`@defer` blocks lazily load parts of a template too.

## 24. What is `HttpClient` and how do you make HTTP calls?

A service for HTTP requests returning Observables. Provide it with `provideHttpClient()`.

```typescript
this.http.get<User[]>('/api/users').subscribe({
  next: users => this.users = users,
  error: err => console.error(err)
});
this.http.post<User>('/api/users', body);
```

## 25. What is an Observable and how does it differ from a Promise?

| Promise           | Observable (RxJS)                                   |
| ----------------- | --------------------------------------------------- |
| Single value      | Zero, one, or many values                           |
| Eager             | Lazy (runs on subscribe)                            |
| Not cancellable   | Cancellable via `unsubscribe`                     |
| Limited operators | Rich operators (`map`, `filter`, `switchMap`) |

Always unsubscribe (or use `async` pipe / `takeUntilDestroyed`) to avoid memory leaks.

```typescript
users$ = this.http.get<User[]>('/api/users').pipe(map(u => u.filter(x => x.active)));
```

## 26. What are Template-Driven vs Reactive Forms?

| Template-Driven                 | Reactive                                        |
| ------------------------------- | ----------------------------------------------- |
| Logic in template (`ngModel`) | Logic in class (`FormGroup`, `FormControl`) |
| Simple forms                    | Complex, dynamic forms                          |
| Harder to test                  | Easy to test, explicit                          |

```typescript
form = new FormGroup({
  email: new FormControl('', [Validators.required, Validators.email]),
  password: new FormControl('', Validators.minLength(8))
});
```

```html
<form [formGroup]="form" (ngSubmit)="submit()">
  <input formControlName="email">
</form>
```

Import `ReactiveFormsModule` or `FormsModule`.

## 27. What are Signals?

Signals (Angular 16+) are reactive primitives that track state and update the UI efficiently.

```typescript
count = signal(0);
double = computed(() => this.count() * 2);
constructor() { effect(() => console.log(this.count())); }

increment() { this.count.update(c => c + 1); }
```

```html
<p>{{ count() }} / {{ double() }}</p>
```

## 28. What are HTTP Interceptors?

Functions that intercept requests/responses globally, e.g., adding auth tokens or handling errors.

```typescript
export const authInterceptor: HttpInterceptorFn = (req, next) => {
  const token = inject(AuthService).token();
  return next(req.clone({ setHeaders: { Authorization: `Bearer ${token}` } }));
};

provideHttpClient(withInterceptors([authInterceptor]));
```

## 29. What is Change Detection?

The mechanism that updates the DOM when data changes. By default, Zone.js triggers a check of the whole component tree after async events.

`ChangeDetectionStrategy.OnPush` checks a component only when its inputs change by reference, an event fires, an observable bound with `async` emits, or a signal changes — improving performance.

```typescript
@Component({ changeDetection: ChangeDetectionStrategy.OnPush, /* ... */ })
```

## 30. What is AOT vs JIT compilation?

- **JIT (Just-in-Time):** compiles in the browser at runtime; slower startup.
- **AOT (Ahead-of-Time):** compiles during build; faster rendering, smaller bundles, earlier template error detection. Default since Angular 9.

```bash
ng build   # AOT production build by default
```
